# Finished / dropped goals

When a weekly reflection says a goal is **done** or **dropped**, do not leave it in `goals/` as current.

1. Copy the goal file into here as `YYYY-MM-<slug>.md` (or move it).
2. Fill **Status**, **Closed on**, **How I know**, **What replaces it**.
3. Remove the current file from `goals/` (if you copied) and delete its line from [goal.md](../goal.md).
4. Keep `work/<slug>/` — that is the evidence history.

Use [_template.md](_template.md). Do not write in the template.
