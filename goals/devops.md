# Learn DevOps

**Slug:** `devops` (matches `work/devops/`)

**One sentence:**
Become an SWE who can design software, ship and run it (cloud and on-prem), and design the workflow around it — including training others — so the system still works when I leave.

**Why this, now:**
I am a SWE (9–5): backend, some frontend, some LLM features, architecture and databases. For the NZ mid-SWE offer, ship/run is the center — coding skill alone is not enough. I have designed systems and touched AWS, but I am not strong at infra. **This phase:** learn DevOps fundamentals from *The DevOps Handbook* (starting with what Lean is, then Part I / The Three Ways) in my own words, plus Friday dumps from the day job. **Later phase (same goal, after a Sunday unlocks):** AWS labs. “Deliver value” means I can name the outcome of the loop in one line (who it was for) — not a business-model book. The day job remains the practice arena; after-hours handbook supports it.

**What “done” looks like:**
I can take a system I would design as an SWE and run the loop myself: build → ship → run → observe → change, on a cloud path and on a server I own — and say in one line who that loop was for. Change is safe enough that I can roll back and see health, not hope. The workflow and enough training/docs exist that someone else could keep it going without me. I have done this in real work, not only in side study.

**This phase’s evidence (before AWS labs):** Part I (The Three Ways) exists as notes in my own words — what each Way is, and how it matches or challenges this goal — plus Friday dumps. Lean / Handbook foundation notes count toward that path.

**What I will not chase in the name of this goal:**
A DevOps/SRE job title, cert collecting, or a catalog of tools I have not run. **Not this phase:** AWS homework, HackerRank, or SWE depth as a substitute for Handbook fundamentals. Company-wide org design disconnected from a system I am shipping. Architecture-only work with no deploy. Counting a normal SWE day as learning with no notes/practice file. Lean canvas / BMG as a parallel study track.
