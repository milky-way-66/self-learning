# Notes

- **Goal:** Relocate / English / DevOps
- **Date:** YYYY-MM-DD
- **Source:** _(book, article, video, course — title + link if any)_
- **Serves this goal by:**

Copy to `work/<goal>/notes/YYYY-MM-DD-slug.md`. Write in your own words. If you cannot explain it, you did not learn it yet.

**5W1H is a prompt, not a form.** Use the questions that help. Skip the rest. Headings only if they help. A short note can be a few paragraphs.

- **What** — what is this?
- **Who** — who does it / who is it for?
- **When** — when does it apply (phase, trigger, sequence)?
- **Where** — where does it live (system, team, context)?
- **Why** — why it exists, and why it matters for the goal
- **How** — how it works, and how I would use it

If something is still unclear, say so at the end.
