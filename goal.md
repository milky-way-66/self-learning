# Goals

Named goals only. Keep the list small. Change a goal only after a weekly reflection.

---

## 1. Learn DevOps

**One sentence:**
Become an SWE who can design software, ship and run it (cloud and on-prem), and design the workflow around it — including training others — so the system still works when I leave.

**Why this, now:**
I am a SWE (9–5). AI has shrunk how much raw coding I do, so I need a wider skill that still supports that role. I have designed and architected systems but have not actually implemented or maintained infra. DevOps here is that missing half: how software is built, made safe, put on machines, and kept runnable by people, not only by me. The day job is the main practice arena: learn from what I already do, and where I can, shift work toward ship / run / observe / change / teach — then write it down. After-hours (handbook, seminar, home lab) supports that; it does not replace it.

**What “done” looks like:**
I can take a system I would design as an SWE and run the loop myself: build → ship → run → observe → change, on a cloud path and on a server I own. Change is safe enough that I can roll back and see health, not hope. The workflow (how we change, review, and learn from the running system) and enough training/docs exist that someone else could keep it going without me. I have done this, not only drawn it — including in real work, not only in side study.

**What I will not chase in the name of this goal:**
A DevOps/SRE job title, cert collecting, or a catalog of tools I have not run. Company-wide org design, hiring systems, or “how teams grow” disconnected from a system I am actually shipping. Architecture-only work with no deploy, no operation, and no one else able to run it. Counting a normal SWE day as learning with no notes/practice file.

**Held since:** 2026-W36 (3 Sep 2026)

## 2. Learn English

**One sentence:**
Use English as a work language — speaking in meetings and writing things others can act on — so I can work remotely or move to a place where work happens in English.

**Why this, now:**
I already know English (about TOEIC 750). I read and chat in it every day, but it has been stale for years and I am not confident using it at work. That is not enough for remote work or relocating to the EU (or another English-working country). The stall is production, not input: I consume English; I do not yet do my job in it. Hard English books still feel difficult — I will keep them, and prefer ones that also serve DevOps, so one stretch of reading can move both goals. When work uses English (meetings, docs, reviews), that is practice — write it down; do not wait only for after-hours drills.

**What “done” looks like:**
I can do professional work in English without switching language or staying quiet. That means live speaking (meetings, explaining design, disagreeing) and writing others use (docs, tickets, reviews). Hard book reading can support this and can compose with DevOps, but “done” is still work production, not finishing more books. Remote or relocation becomes possible because of that capability, not because I waited for a higher test score.

**What I will not chase in the name of this goal:**
Another TOEIC/cert grind as a substitute for speaking and writing. Casual reading and chat alone — I already do that every day and it has not unstuck me (hard books that stretch me, especially ones that also serve DevOps, are allowed). Native-like accent, literary English, or waiting until I feel confident before I produce. English as a school subject disconnected from work.

**Held since:** 2026-W36 (3 Sep 2026)

## 3. NomStamp (iOS)

**One sentence:**
Grow NomStamp — the food-stamp app where people capture what they eat and see it on a map for memory — into a real side product with **100 returning users**.

**Why this, now:**
I am already building this on iOS and spending real time on it. The point is a product people come back to, not “learn iOS” as a course. Learning shipping on iOS happens because the product needs it.

**What “done” looks like:**
100 users who use NomStamp more than once (come back and stamp again — not install-only, not a single tap). Capture → map memory is good enough that return use is natural.

**What I will not chase in the name of this goal:**
Endless polish or feature piles that do not help someone stamp food and return. Rewriting the stack or studying iOS for its own sake. Scale / monetization fantasies before 100 returning users. Letting NomStamp silently eat DevOps/English weeks without naming it on `now.md`.

**Held since:** 2026-W36 (3 Sep 2026)
