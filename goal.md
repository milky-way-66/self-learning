**Current** = one file each under [`goals/`](goals/). **Finished or dropped** = [`goals/finished/`](goals/finished/).

**Sequence (this phase):** Relocate is the why. DevOps (*The DevOps Handbook* → Part I) is the skill center. English rides along (self-study on my work). SWE depth, AWS labs, and HackerRank wait until Part I exists and a Sunday unlocks them. Business is parked ([goals/finished/2026-09-business.md](goals/finished/2026-09-business.md)).

New current goal: copy [`goals/_template.md`](goals/_template.md) → `goals/<slug>.md`, add a row here, create `work/<slug>/`.

Close a goal: copy into `goals/finished/YYYY-MM-<slug>.md` from [`goals/finished/_template.md`](goals/finished/_template.md) (keep the History list), remove the current file and this row.

**History:** each `goals/<slug>.md` has an append-only History at the bottom. First line = when you defined it. Later lines = what a reflection changed. The top of the file is always the current wording only; git still has the full diffs if you need them.
